# Roadmap проекта

План обновляется после каждого небольшого улучшения. Работа идёт по одному пункту: изменение, локальная проверка, push и проверка CI.

## Выполнено

- [x] Flask-приложение связано с Redis.
- [x] Добавлены `/health`, `/ready`, `/info` и `/metrics`.
- [x] Добавлены unit- и интеграционные тесты.
- [x] Настроены GitHub Actions и GitLab CI.
- [x] Закреплены версии Docker-образов.
- [x] Добавлены healthcheck для приложения и Redis.
- [x] Redis скрыт от внешней сети.
- [x] Добавлены идентификаторы запросов и защитные HTTP-заголовки.
- [x] Ruff и минимальное покрытие тестами 85% добавлены в оба CI.
- [x] Добавлен единый JSON-формат ответов для ошибок 404 и 500.
- [x] Логи приложения переведены в структурированный JSON-формат.
- [x] Удалён `'unsafe-inline'` из CSP, стили вынесены в отдельный файл.
- [x] Добавлен Dependabot для Python-зависимостей и GitHub Actions.
- [x] В оба CI добавлен аудит Python-зависимостей на известные уязвимости.
- [x] Добавлен локальный стек Prometheus + Grafana с готовым dashboard.
- [x] Добавлены changelog, единый файл версии и автоматические GitHub Releases.

## План повышения качества и готовности к эксплуатации

Каждый пункт выполняется отдельно: реализация, тесты, обновление документации,
push и проверка CI. Следующий пункт начинается только после подтверждения push.

## Правило готовности

Пункт считается выполненным, если Ruff не находит ошибок, все тесты проходят, покрытие не ниже 85%, оба CI могут выполнить новые проверки и README обновлён при изменении команд или поведения.
